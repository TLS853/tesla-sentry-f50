# QQ 推送、车身涂装和锁车音

这些功能从 2.8.0 起提供。按 [部署说明](DEPLOYMENT.md) 更新 F50 后，刷新网页并打开右上角设置。F50 无需访问 GitHub，仍可使用 Mac 上的离线部署脚本。

## QQ 官方机器人

1. 在 [QQ 开放平台](https://q.qq.com/) 创建机器人，取得 **AppID / AppSecret**，按平台当前要求完成开发配置、测试成员或发布审核。需要单聊/群聊的消息及媒体接口权限；若控制台要求接口 IP 白名单，应填 F50 的实际公网出口 IP。移动网络出口变化可能导致调用失败。
2. 在 QQ 添加机器人为好友，或加入目标群；接收方应允许机器人主动发送消息。
3. 取得**当前 AppID 对应的接收 OpenID**。单聊消息事件 `C2C_MESSAGE_CREATE` 中取 `d.author.user_openid`；群聊事件 `GROUP_AT_MESSAGE_CREATE` 中取 `d.group_openid`。可从你已有机器人服务的已验证事件日志中读取。它们不是 QQ 号码或群号，不同 AppID 下也不通用。没有现成事件接收服务时，先按 [官方事件接入指南](https://bot.q.qq.com/wiki/develop/api-v2/) 接收一次你发给机器人的消息，取得 OpenID 后填入本项目；本项目负责出站推送，不启动事件接收服务。
4. 网页 **设置 → 推送 → QQ 官方机器人**，选择 QQ 单聊或 QQ 群聊，填写上述三个值。密钥只保存在设备端；页面不会读回 AppSecret，修改其他设置时密钥留空即可保留。
5. 可先选「仅文字」，保存并点击「发送测试」。QQ 测试消息不要求归档已有录像。成功后启用推送，再按需改为「封面图片」或「触发摄像头视频」。修改后需保存。

文字包含时间、位置、原因和镜头。封面/视频通过 QQ 官方分片接口直接上传；无需域名、端口映射或关闭网页登录认证。视频沿用本机转码、水印、清晰度与 10–60 秒截取设置；手动合成视频的「推送到已选渠道」也支持 QQ。图片最大 20 MiB、视频最大 30 MiB，避免被 QQ 降级成文件附件。媒体生成或上传失败时，自动推送会回落文字，并在最近结果中说明。

「查看链接前缀」是可选项，只用于附上网页地址，不参与媒体上传。填 F50 的内网地址时，接收手机也须能访问该内网。QQ 是否允许消息内的域名仍由平台设置决定。

新增事件去重、延迟和失败重试与飞书共用；首次启用只建立已有事件基线，不补发历史。选择 QQ 后仍保留飞书配置，当前只向选中的一个渠道发送。主动消息受平台权限、用户开关与频控约束，软件无法绕过；失败时页面显示 QQ 错误码，先检查凭据、接收 OpenID、主动消息开关和额度。网络中断时远端是否已经收件可能无法判断，重试可能导致重复通知。

实现依据：[访问凭证](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/access-token.html)、[消息概述](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)、[本地媒体上传](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/rich-media.html)。使用当前文档的 `https://api.bot.qq.com`，不需要旧的机器人 Token。

## 车机自定义车身涂装

1. 从 [Tesla 官方 custom-wraps 仓库](https://github.com/teslamotors/custom-wraps) 下载**对应车型及年款**的模板或成品。普通照片不具备车身 UV 布局，软件不能仅靠拷贝让它正确贴合车辆。
2. 导出静态 PNG：正方形，边长 512–1024 像素，大小 ≤1,000,000 字节。保留模板尺寸。本项目检查 PNG 签名、结构、CRC 和压缩像素数据，JPEG/WebP 改名成 PNG 会被拒绝。
3. 停车后打开 **设置 → 涂装 → 连接车机 U 盘**。管理期间车机无法读写虚拟 U 盘，录制暂停。
4. 上传 PNG。系统自动创建根目录 `Wraps`，规范文件名为英文字母/数字/空格/下划线/短横线，连同 `.png` 不超过 30 字符。中文或过长名称会带稳定摘要后缀。同名替换需要确认，USB 最多保存 10 个涂装；超过上限请先删除一个。
5. 点击 **完成并恢复车机导出**，再到车机 **玩具箱 → 喷漆车间 → 涂装** 选择。车型、硬件与车机软件需支持该功能。网页只写入文件，不代替车机选择涂装。

文件通过临时文件、fsync 和原子替换写入，操作期间持有 USB 管理锁。不会格式化镜像或删除 `TeslaCam`。也可在「文件管理器」中直接浏览 `Wraps`，但通用上传接口不执行涂装专用校验。

## 锁车音自动转换

1. 打开 **设置 → 锁车语音**。支持 WAV、MP3、M4A、AAC、FLAC、OGG、OPUS、WEBM，源文件最大 20 MiB。
2. 选择起始时间和保留时长，默认取前 5 秒；可保留 0.1–5 秒。上传后自动解码、裁剪、降混为单声道、重采样为 44.1 kHz、编码成 **16-bit PCM WAV**。
3. 转换结果始终命名为 **`LockChime.wav`**，最长 5 秒时约 441 KB，小于 1,000,000 字节；不是简单修改文件扩展名。转换失败时保留先前的待写入文件。
4. 转换结果进入待写入队列。镜像达到配置的空闲时长后，归档同步任务会把它写到 **USB 根目录**，然后移入「已写入」列表。默认空闲等待 10 分钟；车机持续写入或仍处于 U 盘管理模式时不会立即写入。
5. 车机 **玩具箱 → Boombox → 锁车音 → USB** 选用，必要时开启锁车确认音。需要外部行人警示扬声器及支持自定义锁车音的软件；具体菜单以车机为准。一次仅有一个有效 `LockChime.wav`。

历史队列里的 WAV/MP3 也可点击「设为锁车音」，现在会实际转换，而不再仅改名。新上传默认替换队列内的锁车音；同步复制和上传共用归档锁，避免新文件被旧同步操作移走。USB 目标使用原子替换，复制失败保留队列供下次重试。历史其他音频仍保留原来的根目录复制行为，不等同于 Boombox 喇叭音效的独立目录规范。

转换使用设备已有的 ffmpeg，可用配置 `TSF_FFMPEG=/绝对路径/ffmpeg` 指定。如果设备没有 ffmpeg，仍可上传已经是 44.1kHz / 16-bit / 单声道 PCM 的 WAV，并自动裁剪和命名；其他格式会返回明确提示。离线安装包不附带与硬件架构相关的 ffmpeg，请在可联网电脑上准备适合设备的版本再传入。

本项目选择 44.1kHz / 16-bit / 单声道、最多 5 秒作为输出配置，保证文件足够小；这些参数并非全部都是 Tesla 官方强制要求。车辆支持与锁车音菜单参见 [Tesla 车主手册](https://www.tesla.com/ownersmanual/modely/en_ae/GUID-7A32EC01-A17E-42CC-A15B-2E0A39FD07AB.html)。
