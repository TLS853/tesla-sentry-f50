锁车音效

上传喜欢的声音，自动转换为车机锁车音效。

上传后自动裁剪、转换为 44.1kHz / 16-bit / 单声道 PCM WAV，并命名为 LockChime.wav。默认取前 5 秒，输出小于 1 MB；源文件最大 20 MB。支持 WAV / MP3 / M4A / AAC / FLAC / OGG / OPUS / WEBM。
转换成功后替换待写入的锁车音。等待镜像空闲后的归档同步，自动写入 USB 根目录；车机内再选「玩具箱 → Boombox → 锁车音 → USB」。需要车辆支持外部扬声器及自定义锁车音。

车身涂装

为车机上的车辆可视化换一套外观。

自定义车身涂装：上传对应车型模板制作的静态 PNG，512×512–1024×1024，单文件 ≤1 MB，USB 最多 10 个。自动创建根目录 Wraps/ 并规范文件名。普通照片不能自动变成贴合车身的涂装。
Tesla 官方车型模板 · 恢复导出后，在车机「玩具箱 → 喷漆车间 → 涂装」选用。请停车后管理 U 盘，管理期间车机录制暂停。
